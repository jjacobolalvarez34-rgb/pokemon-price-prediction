# Pokémon Price Prediction

## Objective

The objective of this project was to evaluate the ability of different machine learning models to predict Pokémon card prices using features available in the dataset.

## Tools

- Python
- Pandas
- NumPy
- Scikit-Learn
- XGBoost
- CatBoost
- Matplotlib

## Models Evaluated

- Linear Regression
- Random Forest
- XGBoost
- CatBoost
- Stacking
- K-Means for segmentation

## Results

The models were able to partially capture the behavior of card prices; however, their predictive performance was limited.

The project helped identify important limitations related to data quality, feature availability, and the intrinsic variability of the market.

## Key Takeaways

- Data quality is often more important than model complexity.
- Feature selection has a significant impact on predictive performance.
- Ensemble methods can improve results, but they cannot compensate for insufficient information in the dataset.
- Evaluating model limitations is as important as achieving good performance metrics.

## Future Work

- Explore additional data sources.
- Engineer more informative features.
- Analyze temporal effects on card prices.
- Compare alternative ensemble strategies.
